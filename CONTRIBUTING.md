# Contributing to Etabli Projet

This project is proprietary (all rights reserved). Please open an issue before proposing
changes; contributions can only be accepted under a separate written agreement with the
copyright holder.

## House rules
- **Privacy is a hard constraint.** No analytics, telemetry, or third-party SDKs.
- **Dependencies must be FOSS** and buildable from a trusted source. No Firebase, no GMS.
- **Shared design tokens.** Accent #28A745, light/dark/system. Don't fork the palette.

## Releases (maintainer)
Each release commit carries a matching tag (`v1.0`). Keep `fastlane/metadata/` current.
